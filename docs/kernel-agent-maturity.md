# Kernel Agent 成熟度标准（用户裁定 2026-09-26）—— 本阶段主目标

> K8 优化是次要，Kernel Agent 成熟才是主目标。

## 达标定义（可测量）

一次发令后**自主完成 ≥4 轮迭代**，且：
1. 每轮完整链（调研→知识→写→验→测→评）——supervise 全绿；
2. **有真实提升**：bench 历史最优在循环内被自主刷新 ≥1 次；
3. **零人工干预**：无中途修循环、无手工重发、无手工补数据——监督者只看不动手。

## 测量口径（每次发令记录）

- `发令 → 终局` 的轮数 / 有效 bench 轮数（verify 过的）；
- 历史最优刷新次数（benchmark.csv 中 beat_prev 行数）；
- **人工干预次数（目标 =0）**：干预定义=任何对循环进程/代码/数据的中途人工操作
  （修 harness、kill/重启、手工写 candidate、手工改 evidence）；
- 终局产出：最优候选 id + mean_us + 是否 keep 入库。
